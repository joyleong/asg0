# asg0

Interactive multiple-choice quiz on the **Agung Sedayu Group 2027 Learning & Development Work Plan**, with instant right/wrong marking, explanations, a final score and a full answer review.

## Live quiz

Published with GitHub Pages: https://joyleong.github.io/asg0/

## Run locally

Open `index.html` in any browser - no build step, no dependencies.

## Files

- `index.html` - the whole quiz (HTML + CSS + JS in one file)
